# create-opensd

Создаёт проект плагина Open Stream Deck.

```bash
npm create opensd@latest my-plugin
npm create opensd@latest my-plugin -- --lang js
npm create opensd@latest my-plugin -- --lang rust --id com.example.my-plugin
```

По умолчанию проект на TypeScript. Параметры те же, что у `opensd new`.

Документация: https://wiki.opensd.dev/docs/sdk
